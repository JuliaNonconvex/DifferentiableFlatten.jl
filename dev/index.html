DifferentiableFlatten

A flatten function which flattens arbitrary nested data structures (arrays, tuples, named tuples, dictionaries, structs, and combinations thereof) into real vectors, and returns an unflattening function to reconstruct the original data structure. flatten and its unflattening function are differentiable: ChainRules rrules are provided so that differentiation with Zygote and other ChainRules-based systems works through the flattening, which is what makes it the backbone of the structured variable support in NonconvexCore.jl. This was originally part of NonconvexCore.jl.

The package is unexported on purpose: all names are accessed qualified, e.g. DifferentiableFlatten.flatten.

See Usage for the flattening API and Differentiation for the ChainRules support and Docstrings for the full API reference.
